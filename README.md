# PanLogic - Módulo CRUD con Java y JDBC 

## Descripción
Migración de lógica del proyecto PanLogic a Java utilizando JDBC y MySQL, con operaciones CRUD (insertar, consultar, actualizar y eliminar) sobre la tabla `productos`.

## Tecnologías
- Java (JDK)
- Apache NetBeans
- MySQL 8.0 (`panlogic_db`)
- MySQL Connector/J (JDBC)
- Git y GitHub

## Ejecución
1. Tener activo MySQL 8.0 con la base de datos `panlogic_db`.
2. Abrir el proyecto en Apache NetBeans y verificar el `.jar` de MySQL en `Libraries`.
3. Revisar la contraseña en `src/config/Conexion.java`.
4. Ejecutar `PruebaCrudProductos.java` (`Run File`).
